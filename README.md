# MCP Projects Workspace

This repository contains multiple Model Context Protocol (MCP) example projects. Each folder is an independent project focused on a different MCP use case or implementation pattern.

## Project Structure

- `Local_server/` - Minimal MCP server built with FastMCP. This project exposes basic calculator-like tools and is useful for learning the fundamentals of MCP server creation.
- `server_with_fastapi/` - Example that combines FastAPI with MCP. It includes an expense tracker API and demonstrates how to expose the same app through an MCP server.

## Purpose of This Workspace

The goal of this workspace is to explore different ways of building and exposing MCP servers:

- simple local tool servers
- REST API integration
- database-backed services
- MCP exposure of real application logic

## How to Use This Repository

1. Open the folder for the project you want to study.
2. Read that folder's own `README.md` for project-specific setup and instructions.
3. Run the project independently from its own directory.

## Notes

- Each folder is a separate project and can be run independently.
- The root folder is just a workspace index and overview.
- New MCP projects can be added as additional folders in this repository.

## Project Documentation

For specific setup and usage details, refer to the README in each project folder.
